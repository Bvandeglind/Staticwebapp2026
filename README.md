# CloudLaunch - Azure Static Web App Onepager

Een moderne onepager voor het vak Cloud Computing. De pagina legt uit hoe een static web app werkt en hoe je deze publiceert via Microsoft Azure met een gekoppelde GitHub repository.

## Bestanden

- `index.html` - de volledige onepager
- `styles.css` - alle styling, responsive layout en animaties

## Publiceren via GitHub en Azure

1. Maak een nieuwe GitHub repository.
2. Upload `index.html` en `styles.css`.
3. Ga naar Microsoft Azure Portal.
4. Maak een nieuwe **Static Web App**.
5. Koppel je GitHub repository.
6. Laat Azure de GitHub Actions workflow aanmaken.
7. Open de live URL zodra de deployment klaar is.
