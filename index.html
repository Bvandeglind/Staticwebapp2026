Het concept

Een static web app is snel, simpel en perfect om cloud deployment te leren.

Een static web app bestaat uit bestanden die direct naar de browser worden gestuurd. Denk aan index.html, styles.css en afbeeldingen. Azure zorgt voor hosting, beveiligde HTTPS en koppeling met GitHub. Jij focust op bouwen en publiceren.

HTML/CSS → GitHub repo → Azure Static Web App → Live URL
